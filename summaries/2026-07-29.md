### More Tailscale tricks for your jailbroken Kindle - (Hacker News)

https://tailscale.com/blog/jailbroken-kindle-proxy-tun-modes

# Summary

Open-source developers have significantly enhanced Tailscale's functionality on jailbroken Kindles, expanding beyond basic connectivity. The updated implementation now includes Tailscale SSH enabled by default, a proxy mode that allows apps like KOReader to access other devices on your network, and full TUN mode support for improved device-level networking on compatible Kindles.

The proxy mode is particularly useful, solving the previous limitation where apps couldn't route traffic through Tailscale's network layer. Users can now configure apps to use SOCKS5 or HTTP CONNECT proxies, enabling practical applications like connecting to Calibre servers, Wallabag, Audiobookshelf, and self-hosted RSS feeds directly from their e-readers. Additionally, a dedicated Tailscale plugin for KOReader works on Kindle, Kobo, and PocketBook devices, making it easier to access content servers without requiring the Kindle itself to be part of the tailnet.

### Codex Security - (Hacker News)

https://github.com/openai/codex-security

# Summary

**Codex Security** is an open-source CLI tool and TypeScript SDK developed by OpenAI that helps developers find, validate, and fix security vulnerabilities in their code. It allows users to scan repositories, review changes, track findings over time, and integrate security checks directly into CI/CD pipelines.

The tool requires Node.js 22+ and Python 3.10+ and can be installed via npm. Users can authenticate using either ChatGPT credentials or an API key, and the basic workflow involves running `npx codex-security scan .` to analyze code for vulnerabilities. It supports both interactive use and automated CI environments, with scan history tracked for monitoring security issues over time.

### Cracking Windows Open: Porting RADV to Win32 - (Hacker News)

https://www.collabora.com/news-and-blog/news-and-events/cracking-windows-open-porting-radv-to-win32.html

# Summary

Collabora has successfully ported RADV, the open-source Mesa Vulkan driver for AMD GPUs, to Windows, building on previous feasibility work by Faith Ekstrand. The project progressed from displaying a basic 3D model to running Counter-Strike 2, demonstrating that an open-source Vulkan implementation can work on Windows despite significant technical challenges. Key improvements included better command stream handling, support for advanced GPU features like tessellation and sparse bindings, and development of enhanced reverse-engineering tools to understand Windows' undocumented WDDM2 interface.

The primary challenge ahead is achieving production-ready stability, which requires establishing a stable, documented interface with AMD's proprietary kernel-mode driver. Currently, the port relies on fragile reverse-engineered knowledge of private data structures that can change between driver versions. Additional work is also needed on presentation performance through DXGI swapchains and zero-copy image swaps, potentially requiring collaboration with AMD and Microsoft. Despite these hurdles, the project demonstrates the viability and value of an open-source Vulkan driver for Windows users.

https://github.com/twalichiewicz/HNewhere

# HNewhere Summary

HNewhere is a lightweight userscript that enhances article reading by automatically detecting and displaying Hacker News discussions in a sidebar without leaving the current page. The tool works by identifying matching Hacker News stories, loading their comments, and allowing users to browse discussions while reading articles.

The script requires a userscript manager (like Tampermonkey or Violentmonkey) to install and offers features including automatic story detection, a resizable sidebar, collapsible comments, and direct links to reply on Hacker News. ### Transformer Transformer: A Unified Model for Motion-Conditioned Robot Co-Design - (Hacker News)

https://transformer-transformer.github.io/

# Summary

**Transformer Transformer** is a unified diffusion-based model that generates optimized robot designs for specific manipulation tasks. Given a target end-effector motion (e.g., from human demonstration) and a reward function, the system generates a complete robot embodiment including geometry, kinematics, inertia, and motors—then directly controls that robot to execute the motion. The approach uses RoboTokens, a compact tokenization scheme that represents any robot (quadrupeds, humanoids, arms) as a sequence of 28-101 tokens, enabling a single architecture to span multiple embodiment types and use cases.

The key innovation is **Dynamics Self-Guidance**, which enables zero-shot optimization for unseen rewards. Since the model predicts both embodiment and dynamics jointly, predicted rewards become differentiable with respect to robot parameters. Gradients from the reward function flow back through the entire episode to optimize embodiment tokens, allowing the model to ask itself "how should this robot change to maximize reward?" Experiments demonstrate significant improvements—including a 73% reduction in tracking error and 30% reduction in max joint speed for a cloth-flinging task compared to the original design—across diverse design spaces and without task-specific training.

### Substack writers, you need a website - (Hacker News)

https://elizabethtai.com/2026/06/10/substack-writers-you-need-a-website/

# Summary

Elizabeth Tai argues that Substack writers should maintain their own independent websites rather than treating Substack as their primary digital home. While Substack offers convenience and built-in audiences, relying entirely on any platform makes writers "digital sharecroppers" vulnerable to sudden policy changes, algorithmic shifts, and corporate decisions beyond their control. Tai emphasizes that platforms like Substack, Twitter, and Medium have repeatedly disappointed users, making it essential for writers to own their digital real estate through a personal domain.

The solution, according to Tai, is adopting the POSSE strategy (Publish On your own Site, Syndicate Elsewhere): maintain a personal website as your authoritative hub while using platforms like Substack and social media merely as distribution channels to drive readers back to your site. She points to writer John Scalzi, who has maintained an independent blog for 28 years, as an example of how long-term digital autonomy and visibility is achieved. By anchoring your work on your own platform with RSS feeds, writers can weather platform changes and preserve their life's work independently.

### Half-Life ported to Mac OS 9 - (Hacker News)

https://mac-classic.com/news/half-life-ported-to-mac-os-9/

# Summary

Half-Life has been successfully ported to Mac OS 9 for PowerPC-based Macintosh computers, 28 years after the game's original release. The port was created by GitHub user doctashay using a fork of the Xash3D FWGS engine and includes the main game, multiplayer support, and expansions Blue Shift and Opposing Force. The game is fully playable from start to finish on G3 and G4 PowerPC computers running Mac OS 9.0 or later, though performance depends heavily on GPU capabilities.

This achievement is particularly significant given that Valve originally planned to release Half-Life for Mac OS 9 in 1999 but cancelled it before launch, and didn't bring the game to Mac OS X until 2013. The port represents a major accomplishment for the Macintosh gaming community and demonstrates continued dedication to preserving classic gaming experiences on legacy systems.

### ReFrame – The EPaper Camera - (Hacker News)

https://reframe.camera/

# reFrame Summary

reFrame is an experimental camera featuring a six-color ePaper display that captures and displays one deliberate photo at a time. Photos are dithered to work with the limited color palette, creating a distinctive aesthetic reminiscent of newspaper halftones or retro video games. Each image takes 15 seconds to fully appear on screen as the display physically moves ink particles into place, offering a digital polaroid-like experience. Since ePaper retains images even when powered off, the camera doubles as a desk photo frame, with the only way to clear the screen being to take a new photo.

The camera is an open-source passion project by Kaloyan Kolev that uses off-the-shelf components (Raspberry Pi Zero, Pi Camera 3, and a color eInk display) and can be built by anyone following the GitHub guide. While not yet available for purchase, photos taken are saved digitally and can be downloaded in both original and dithered formats through a web dashboard.

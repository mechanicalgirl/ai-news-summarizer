### Shipping JPEG XL in Chrome - (Hacker News)

https://developer.chrome.com/blog/jpeg-xl-in-chrome

# Summary

Chrome is now shipping support for JPEG XL, a next-generation image format starting with Chrome 155. JPEG XL offers 30-50% better compression than traditional JPEG, supports lossless compression, HDR, and progressive decoding, making it particularly valuable for high-fidelity photographic images. The format was implemented using jxl-rs, a pure Rust decoder that prioritizes memory safety while maintaining performance comparable to unsafe alternatives through SIMD optimizations.

The decision to ship JPEG XL was driven by consistent developer feedback and its popularity in the Interop Project, Chrome's cross-browser compatibility initiative. Chrome integrated a memory-safe Rust implementation to eliminate security vulnerabilities inherent in traditional C++ image decoders, which are frequent attack targets. The implementation has been thoroughly tested and verified without discovering any memory safety bugs, demonstrating Rust's advantages for critical browser components.

### A font recreated from photographs of classic Commodore 64 keycaps - (Hacker News)

https://github.com/szabadkai/c64-keyboard-font/

# Summary

This GitHub repository contains a custom font recreated from photographs of classic Commodore 64 computer keycaps. The project provides desktop fonts (TTF/OTF), webfonts, editable outlines, and a preview tool that allows users to see and test the font. It includes uppercase letters, numbers, punctuation, function-key labels (F1-F12), and all 63 PETSCII graphic symbols that were printed on the original C64 keyboard.

The font is designed as an unofficial, photo-based reconstruction that captures the geometric proportions and styling of the original keycap lettering rather than being an exact trace. Users can install the font and use it in their applications, with a convenient preview.html file included to experiment with the special characters and PETSCII symbols before copying them to their own work.

### Write Like It's 1866: LLMs Relearn Telegraphese - (Hacker News)

https://fiveminutesforward.com/post/2026-10-04-telegraph-test/

# Summary

This article demonstrates that instructing large language models (LLMs) to write in "cablese"—a compressed, telegraph-operator style that drops articles and filler while preserving facts—reduces output tokens by 40-49% without sacrificing information recovery. Testing across multiple model families shows that downstream models can read these compressed records at near-perfect fidelity (0.99-1.10 recovery ratios), making this a simple, zero-training optimization that effectively doubles context capacity or halves API costs for machine-to-machine communication.

The technique works because cablese conventions are already embedded in LLM training data through historical telegraph communications and related compressed formats (SMS, headlines, etc.). Unlike old codebook-based compression which only achieved ~10% savings, this style-based approach achieves substantial token reduction. The method is particularly effective for agent memory systems and inter-model communication, requiring only a one-sentence instruction with no examples needed, though compression effectiveness varies by model (40-49% range) and doesn't work well with models that have mandatory reasoning enabled.

### Rust's derive often implies inline - (Hacker News)

https://yossarian.net/til/post/rust-s-derive-often-implies-inline/

# Summary

Rust's `#[derive(...)]` macro automatically applies the `#[inline]` attribute to generated trait implementations like `Debug` and `Clone`. While this is usually beneficial for simple, trivial implementations, it can cause significant problems with complex nested structures. Large error hierarchies with many fields can result in substantial code bloat when the compiler inlines these Debug implementations repeatedly throughout a codebase.

The author discovered this issue when optimizing the `uv` project and found that preventing inlining of a single Debug implementation reduced binary size by approximately 160KB. This suggests that rustc doesn't currently limit the size or frequency of inlining for derived implementations, which can lead to unexpectedly large binaries in real-world applications with deeply nested error types and numerous fields.

### Strands Decider 2B: a small, open-source, decision model - (Hacker News)

https://strandsagents.com/blog/introducing-strands-decider/

# Summary

Strands has released **Strands Decider 2B**, an open-source decision model designed for fast, efficient AI agent operations. Unlike traditional large language models that generate arbitrary text, decision models are specialized to select from predefined options and assign confidence scores—making them faster, more reliable, and better suited for agentic workflows. The 2-billion parameter model can run locally on CPU or GPU, returning answers in tens of milliseconds, while providing high-quality reliability scores unavailable from frontier LLM APIs.

The model uses a streamlined architecture based on Qwen 3.5-2B, replacing the traditional text-generation head with a "pointer head" that scores options. Strands has released it as open source with full training data and scripts. In benchmarking, Strands Decider 2B ranks 3rd among 2B-class decision models on accuracy and calibration (JevBench), with median decision latency around 115ms on standard hardware. The team positions this as foundational for the emerging class of decision models expected to drive innovation in agentic AI.

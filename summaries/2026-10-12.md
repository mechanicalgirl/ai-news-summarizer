### Show HN: PS2 games statically recompiled to WebAssembly - (Hacker News)

https://github.com/snuri00/ps2-web-recomp

# Summary

This GitHub repository presents ps2-web-recomp, a project that runs PlayStation 2 games directly in web browsers by converting the console's machine code into WebAssembly and a native runtime. Rather than traditional emulation, the system uses static recompilation to translate the PS2's Emotion Engine code into C++, which is then compiled to WebAssembly. The implementation includes a reimplemented PS2 kernel, vector unit support, and WebGPU-based graphics rendering. Demonstrated games include Gran Turismo 4 and God of War II, both running at full speed with proper audio, visual effects, and save functionality.

The project employs sophisticated optimization techniques across multiple components: the Graphics Synthesizer is implemented via WebGPU compute shaders with native memory layouts, vector unit microprograms are compiled to SIMD C++, and various caching and batching strategies were implemented to maximize performance. Through careful profiling and optimization—including texture caching, compute dispatch reduction, and proper thread scheduling—the developers achieved impressive results, with games running at 50-60 frames per second at native or higher resolutions on integrated GPUs.

### Fingerprints are the new cookies - (Hacker News)

https://royfish.dev/fingerprints-are-the-new-cookies

# Summary

Browser fingerprinting has become the new method for tracking users online, replacing traditional third-party cookies. This technique collects data from both network requests (IP address, browser type, language settings) and hardware measurements (GPU, CPU, display resolution, installed fonts) to create a unique digital profile. Even when users disable cookies, clear their browser history, use VPNs, or switch devices, fingerprinting can still reliably identify them. This data is then sold to advertisers and other entities, creating detailed profiles used to target ads, influence behavior, and enable surveillance—with users having little recourse.

Google, the world's largest ad company, orchestrated this shift by initially promising to eliminate cookies while actually developing fingerprinting-based alternatives through its Privacy Sandbox initiative. The technique works by combining multiple data points, each providing bits of identifying information that collectively narrow down a user's identity to practical uniqueness—similar to how a guessing game like Akinator identifies characters through sequential questions. Only privacy-focused browsers like Brave, Tor, and Mullvad Browser offer meaningful protection against fingerprinting, while mainstream browsers like Chrome, Safari, and Firefox leave users vulnerable to this increasingly sophisticated form of digital tracking.

### Secret of Orange Cats Revealed After 60-Year Search - (Hacker News)

https://www.sciencealert.com/secret-of-orange-cats-finally-revealed-after-60-year-search

# Summary

After more than 60 years of mystery, researchers have finally identified the genetic cause of orange fur in cats: a 5 kilobase DNA deletion in a non-protein-coding region that affects the Arhgap36 gene. This deletion causes the gene to be overexpressed in melanocytes (pigment cells), suppressing dark eumelanin pigments and shifting them to reddish-yellow pheomelanin pigments. The mutation is located on the X chromosome, explaining why most orange cats are male, while female orange cats typically display patchy calico or tortoiseshell patterns due to random X chromosome inactivation in their cells.

The discovery, made by two independent research teams and published in Current Biology, confirms long-held predictions about the sex-linked inheritance of orange coloring in cats. Interestingly, while orange cats have a reputation for being less intelligent, this mutation appears to have no negative effects on their health or cognition—the Arhgap36 gene is overexpressed only in developing pigment cells, not throughout the body.

### Type-safe HTML templating in Zig - (Hacker News)

https://lalinsky.com/2026/10/11/type-safe-html-templating-in-zig.html

# Summary

Lukáš Lalinský presents **zt**, a type-safe HTML templating library for Zig inspired by Go's Templ and JavaScript's JSX. Templates are parsed and transpiled to Zig code during the build process, allowing full compile-time type checking and direct integration with application code. This approach eliminates runtime template errors and enables efficient rendering without allocations—just writing directly to a Writer interface.

The library prioritizes security with automatic HTML escaping by default, URL scheme validation, and required proper element closure to prevent XSS vulnerabilities. Templates use readable HTML syntax with embedded Zig expressions and control flow, making them feel like writing actual HTML rather than a domain-specific language. The solution demonstrates that even low-level languages like Zig can effectively support modern web development patterns when combined with arena allocators and compile-time features.

### Total Annihilation, rebuilt for modern computers - (Hacker News)

https://nanolathe.gg

# Nanolathe Summary

Nanolathe is an open-source, MIT-licensed engine that faithfully reimplements the classic real-time strategy game Total Annihilation for modern computers. It features a modern GPU renderer with improved graphics including lighting and glow effects while maintaining the option to view the classic appearance. The engine is available as a browser-based demo (with three original campaign missions) and as a native beta for Windows, Mac, and Linux that requires original Total Annihilation game files.

The project emphasizes accessibility and transparency—players can study the engine's documented code, modify it, and build upon it. It supports single-player campaigns, skirmish modes, survival modes, and online multiplayer for 2-10 players. The engine's code and clean-room research are fully open to explore, making it an educational resource as well as a way to experience the classic game with modern graphical improvements.

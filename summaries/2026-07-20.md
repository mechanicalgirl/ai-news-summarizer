### Xiaomi-Robotics-1 - (Hacker News)

https://robotics.xiaomi.com/xiaomi-robotics-1.html

# Summary

Xiaomi-Robotics-1 is a large-scale robot foundation model trained on over 100,000 hours of embodiment-free manipulation data spanning 1,700+ real-world scenarios, combined with 7,200+ hours of in-house robot data. Following the LLM training paradigm, the model uses two stages: pre-training on diverse UMI trajectories to learn general action generation, and post-training to align these capabilities with specific robot embodiments and natural language instructions. Crucially, the model demonstrates clean scaling behavior—both validation error and real-robot success rates improve steadily as data and model size increase, with no signs of saturation.

The trained model achieves strong practical performance, learning new complex tasks like phone packing and laundry loading from just 10-40 hours of demonstrations per task (reaching 75-85% success rates), while simultaneously achieving state-of-the-art results on four mainstream simulation benchmarks. This work demonstrates a viable approach to scaling robot learning by breaking the data bottleneck through large-scale embodiment-free pre-training, with the scaling benefits successfully transferring to real-world robotic performance.

### LoRA Speedrun – a public wall-clock leaderboard for fine-tuning techniques - (Hacker News)

https://github.com/Saivineeth147/lora-speedrun

# Summary

This GitHub repository hosts "LoRA Speedrun," a competitive leaderboard for optimizing Low-Rank Adaptation (LoRA) fine-tuning speed. It provides a frozen task, frozen hardware (single L40S GPU), and public wall-clock timing records, allowing researchers to compete in fine-tuning small language models (Qwen2.5-1.5B and SmolLM2-1.7B) to specific performance targets. The project democratizes benchmarking by offering free verification runs on Modal's infrastructure, eliminating the need for expensive hardware access.

The speedrun aims to identify the fastest parameter-efficient fine-tuning techniques through an adversarial, apples-to-apples competition—similar to the successful nanoGPT pretraining speedrun. Submissions require code review, automated security screening, and independent verification with 3 fresh seeds before appearing on the leaderboard. The current record stands at 6 minutes 5 seconds using sequence packing and completion-only loss masking, and the project invites community contributions to explore techniques like DoRA, rsLoRA, PiSSA, and custom kernels to beat existing times.

### Moonshine: Lets you stream games from your PC to any device running Moonlight - (Hacker News)

https://github.com/hgaiser/moonshine

# Moonshine Summary

Moonshine is a headless streaming server written in Rust that allows users to stream games from a Linux PC to any device running the Moonlight client. It enables remote gameplay by transmitting keyboard, mouse, and controller inputs back to the host PC. Key features include isolated streaming sessions (each running in its own compositor), no monitor requirement, hardware video encoding (H.264, H.265, AV1), HDR support, and full input/audio streaming capabilities.

The project is Linux-only and requires systemd, a GPU with Vulkan video encoding support (NVIDIA RTX, AMD RDNA2+, or Intel Arc), and Moonlight v6.0.0 or higher. Unlike Sunshine (a similar cross-platform alternative), Moonshine excels at running isolated streaming sessions separate from the desktop, allowing the host PC to remain usable while streaming. Installation is available via AUR on Arch Linux or from source, with configuration managed through a TOML file that supports application management and automatic application scanning.

### Self-Powered Trailers Promise Leaner Freight Runs - (Hacker News)

https://spectrum.ieee.org/self-powered-trailers-freight-decarbonization

# Summary

The freight industry is racing to electrify semitrailers through self-powered retrofit kits as a cost-effective alternative to replacing entire tractor units. These systems use electric axles powered by onboard batteries charged through regenerative braking, rooftop solar panels, and grid connections during stops. Nivalis Energy Europe recently began commercial testing of its 60-kWh system in Germany, projecting annual diesel savings of up to 7,000 liters per trailer, while competitors like Trailer Dynamics offer larger battery configurations (up to 551 kWh) claiming up to 40 percent fuel savings.

The competitive landscape includes multiple approaches: ZF's TrailTrax platform (adopted by major trailer manufacturers Krone and Kässbohrer), Range Energy's North American 300-kWh system, and others. The key debate centers on optimal battery size and cost-effectiveness rather than universal design standards. With the European Investment Bank backing Trailer Dynamics with €25 million and industrial production expected to begin in 2028, electrifying trailers rather than tractors appears to be gaining industry consensus as the fastest path to decarbonizing long-haul freight while avoiding the infrastructure challenges of fully electric trucks.

### Korg PS-3300 is back - (Hacker News)

https://www.korg.co.uk/blogs/updates/ps3300

# Summary

Korg has revived the legendary PS-3300 synthesizer, one of the rarest and most sought-after analog synths in music history. Originally produced between 1977-1981 with fewer than 50 units made, the PS-3300 was famously used by artists like Keith Emerson, Kraftwerk, and Jean-Michel Jarre. The new PS-3300 is a faithful hand-crafted reproduction created in collaboration with original designer Fumio Mieda, meticulously recreating both the sound and physical design while using modern, reliable components where necessary.

The instrument features three independent sound generator units delivering the sonic equivalent of 144 MS-20s, with extensive modulation capabilities, 12-note microtuning, and a semi-modular design. Korg is releasing the PS-3300 in extremely limited quantities throughout the year via a structured registration process to ensure fair access. Each unit is handcrafted in Japan and includes a custom hard case, making it a premium piece of music history for synthesizer enthusiasts and forward-thinking musicians.

### Claude Code uses Bun written in Rust now - (Hacker News)

https://simonwillison.net/2026/Jul/19/claude-code-in-bun-in-rust/

# Summary

Claude Code v2.1.181 and later versions now use Bun rewritten in Rust instead of the original JavaScript version. According to Jarred Sumner, this change resulted in a 10% faster startup time on Linux, though most users didn't notice the difference. Simon Willison verified this by examining his Claude Code installation and found embedded Rust source files and version information confirming the Rust-based Bun (v1.4.0) is running in production across millions of devices.

The article demonstrates that the migration was successful and transparent to end users—a practical example of how behind-the-scenes performance improvements can be deployed without disrupting the user experience. The Rust version has since been released as Bun canary for public use.

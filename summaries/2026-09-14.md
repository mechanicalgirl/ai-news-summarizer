### Fable 5.1 Solves the Cyphral Distich, a 370-year-old cipher - (Hacker News)

https://www.vals.ai/blogs/fable-solves-cyphral-distich

# Summary

Claude Fable 5.1 successfully solved Sir Thomas Urquhart's Cyphral Distich, a 370-year-old unsolved cipher consisting of 64 numbers across two lines. The AI discovered that the key wasn't an external cipher alphabet but the text itself: each number in the cipher serves as a word index into the corresponding Proquiritation (of which there are exactly 32), with the first letter of that word forming the plaintext. The solution revealed a royalist prayer for King Charles II: "O GOD UPHOLD KING CHARLS THE SECOND AND MAKE HIM THE SUPREME RULER OF THIS LAND."

Using the same methodology, Claude also deciphered Urquhart's larger Cyphral Octastich (285 numbers) from his work *The Jewel* (1652), which similarly used page numbers as indices into the book itself. The AI solved both ciphers through careful analysis and pattern recognition rather than complex cryptanalysis, demonstrating that persistent examination of historical puzzles—once a bottleneck requiring significant human attention—can now be accomplished by AI models that recognize tractable problems and follow clues systematically.

https://github.com/callbacked/kinesis

# Summary

Kinesis is a native macOS application that enables users to control their Mac using a Meta neural band (a wearable EMG device). The app allows users to perform various gestures like swiping between desktops, opening Mission Control, controlling music, and adjusting volume or brightness through customizable gesture mappings. ### A 386 PC for Your RP2350 - (Hacker News)

https://github.com/rh1tech/frank-386

# Summary

FRANK 386 is a full i386 PC emulator ported to the Raspberry Pi Pico 2 (RP2350) that enables retro computing on embedded hardware. It supports up to 8MB of RAM, VGA/HDMI graphics output, multiple sound devices (AdLib, Sound Blaster 16, PC Speaker), and can boot DOS, Windows 3.x, Windows 95, and Linux from SD card disk images. The project is based on Tiny386 and works with several compatible boards including the FRANK development board, Murmulator, Olimex PICO-PC, and Waveshare RP2350-PiZero.

The emulator includes runtime management features such as a disk manager (Win+F12) for hot-swapping disk images and a settings menu (Win+F11) for configuring CPU generation, memory size, sound devices, and other parameters. It supports multiple input methods including PS/2 keyboards, USB keyboards, mice, and NES gamepads. The project is open-source (MIT License) with detailed build instructions and configuration guides for different board variants.

### An atlas of periodic solutions to the three-body problem - (Hacker News)

https://www.threebodyorbits.com/

# Summary

This article presents an interactive atlas of 3,915 periodic solutions to the three-body problem—a classic physics challenge involving three masses orbiting each other. While the three-body problem lacks a general mathematical solution, these periodic orbits represent special cases where three masses return to their exact starting positions and velocities after one complete cycle.

The atlas is an interactive visualization tool that organizes these orbits by similarity, grouping related orbits into families that form "islands" on a digital map. Users can explore individual orbits, watch them animate, perturb them from their trajectories, and compare them through a battle and leaderboard system, making this a dynamic resource for studying this fundamental physics problem.

### Apple's Siri AI Can Be Swapped Out for Claude, ChatGPT, Code Shows - (Hacker News)

https://www.macrumors.com/2026/09/14/siri-can-be-swapped-out-for-chatgpt-claude/

# Summary

Code analysis of iOS 27 and macOS Golden Gate reveals that Apple has engineered Siri's architecture to work with third-party AI models at a deep level. Two mechanisms enable this interoperability: "Model Delegation" allows AI assistants like Claude to function as Siri extensions (similar to the existing ChatGPT integration), where they can interpret requests and hand tasks back to Siri when system access is needed. A second protocol called "Inference Provider" in Model Manager Services goes further by allowing Apple's server-side Siri model to be completely replaced by alternative models like GPT-5.6, enabling them to access Apple's tools and personal data while using Siri's interface.

While currently only ChatGPT is available as an "Ask..." option in the macOS release candidate, Apple has not yet opened these capabilities to third parties or made them front-facing to users. The European Union's Digital Markets Act likely influenced this design, as it requires Apple to give third parties effective access to iOS hardware and software features available to Apple's own services, including Siri.

### Drawably: Hand-Drawn UI Controls - (Hacker News)

https://github.com/Danilaa1/drawably

# Drawably Summary

Drawably is a lightweight JavaScript library that creates hand-drawn UI controls with animated pen-sketch styling. It generates unique sketches on each mount using seeded randomness, with strokes that animate with a "boiling" doodle effect. The library is extremely minimal—just ~9 KB of gzipped JavaScript and a 3 KB stylesheet with zero dependencies—and includes React wrappers that add under 1 KB.

The library provides a comprehensive set of hand-drawn UI components including buttons, checkboxes, inputs, cards, badges, and decorative elements like underlines and arrows. All controls maintain functional accessibility by keeping real HTML inputs in the DOM while layering invisible SVG sketches underneath. Features include customizable variants, state management (loading/error/success), color theming via CSS custom properties, and support for reduced-motion preferences. An optional 31 KB custom pen font is available for consistent hand-drawn typography throughout interfaces.

### OpenArch – PyTorch implementations of modern LLM architectures - (Hacker News)

https://github.com/anuj0456/OpenArch

# OpenArch Summary

OpenArch is a GitHub repository containing hand-written PyTorch implementations of modern open-source LLM architectures (including Llama, Qwen, DeepSeek, Gemma, and others) built from scratch for educational purposes. The implementations prioritize readability and clarity over production performance, with each model housed in a single, well-documented file that makes architectural choices—such as attention types (MHA, GQA, MLA), normalization methods, positional encodings, and mixture-of-experts configurations—explicit and easy to compare.

The repository is actively seeking contributors to implement additional models from Sebastian Raschka's LLM Architecture Gallery (targeting 72 total architectures). It currently has implementations marked as complete for numerous text-based models and a few multimodal models, with others still under construction. The project emphasizes learning and understanding how modern LLMs are built, making it an accessible resource for practitioners interested in deepening their knowledge of transformer architectures.

### Devil's Arrows: Ancient builders hauled 55k-lb stones 11 miles for UK stone row - (Hacker News)

https://www.sciencedaily.com/releases/2026/09/260909005152.htm

# Summary

Researchers from Curtin University and the University of York have identified the source of Britain's Devil's Arrows—a 7-meter-tall prehistoric stone row near Boroughbridge in northern England. Using a non-invasive mineral analysis technique, scientists determined that the 25-tonne stones were deliberately transported 18 kilometers (11 miles) from Brimham Rocks around 4,000 years ago, rather than from the closer Plumpton Rocks as previously thought.

The discovery reveals that ancient builders prioritized cultural, spiritual, or symbolic significance over convenience when selecting their materials. This finding challenges previous assumptions about prehistoric monument construction and demonstrates remarkable engineering skill and coordination. Researchers plan to use their innovative sampling technique on other standing stones and conduct targeted excavations to better understand how these extraordinary monuments were built and transported.

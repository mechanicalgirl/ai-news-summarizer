### Inkitt Builds a One-Shot PR Creator with Resumable Agent Orchestration - (InfoQ)

https://www.infoq.com/news/2026/11/inkitt-one-shot-pr-creator-agent/

# Summary

Inkitt has developed an automated pull request (PR) creator that uses resumable agent orchestration to automate small, low-risk code changes from task intake through draft PR creation. Triggered via Slack, Linear, or API, the system runs on remote infrastructure and features an event-driven orchestrator that coordinates short-lived agent containers, persisting run state in a database to allow execution resumption. The architecture separates decision-making from side effects, with the orchestrator managing transitions between stages (specification, implementation, verification, CI repair, and merge conflict resolution) while maintaining strict security boundaries—agent containers receive limited credentials and cannot access sensitive systems or restricted code paths.

The system implements multiple safeguards including boundaries on automation scope (excluding database migrations, authentication code, and package updates), maximum retry limits, and idempotent operations to handle duplicate webhook deliveries. While the orchestration handles most workflow automation, human approval remains mandatory—developers must review and approve the final PR before merge. Inkitt emphasizes that the implementation challenges around idempotency, permissions, and state management were more complex than the AI model itself, demonstrating a pragmatic approach to production coding agents that balances automation with safety and control.

### Amazon ECS Gateway Arrives with Generated Hostnames and No Custom Domain Support - (InfoQ)

https://www.infoq.com/news/2026/11/introducing-amazon-ecs-gateway/

# Summary

Amazon recently launched ECS Gateway, an account-level ingress resource that simplifies networking for containerized workloads by allowing platform teams to define networking infrastructure once, which application teams can then attach services to via connectors. Each service automatically receives a generated hostname in the format `https://<unique-id>.ecs.<region>.on.aws`, and the service is available at no additional charge across all commercial AWS regions.

However, the feature has drawn criticism from practitioners due to a significant limitation: it does not support custom domains. The gateway uses host-based routing on a shared Application Load Balancer, making it impossible to use CNAMEs or custom domain names, which severely limits its usefulness for production environments. Additionally, the documentation reveals a cost consideration—the gateway provisions multiple load balancers as services scale and does not consolidate or repack them when services leave, meaning partly-filled load balancers continue to incur charges.

### Docker Urges Isolation and Governance for AI Agent Security - (InfoQ)

https://www.infoq.com/news/2026/11/docker-ai-agent-security/

# Summary

Docker has published a security guide identifying five major risks for AI agents operating with limited human oversight: prompt injection, tool misuse and poisoning, excessive autonomy, credential exposure, and data exfiltration. The core issue is that agents autonomously select and chain tools together at runtime, making traditional security controls insufficient. Docker emphasizes that prompt injection—where attackers embed hidden instructions in content agents read—cannot be reliably prevented through model instructions alone, so the focus should be on limiting what a compromised agent can access.

Rather than relying solely on model improvements, Docker advocates for isolation and governance as primary defenses. This includes restricting agents to only necessary tools, implementing access boundaries to prevent reaching unauthorized systems, and avoiding "YOLO mode" (automatic approval of all actions). Docker supports OWASP's recommendations for access verification, behavioral monitoring, and operational boundaries. Real-world incidents illustrate the risks: a coding agent deleted a developer's home directory, and another caused a 13-hour production outage when given excessive permissions.

https://www.infoq.com/news/2026/11/litert-tensor-api/

# Summary

Google has introduced the LiteRT Tensor API, a lightweight C++ API that enables developers to build, customize, and optimize machine learning models for direct on-device execution across CPU, GPU, and NPU hardware without requiring platform-specific rewrites. The API addresses traditional challenges by allowing developers to define computation graphs in C++, providing capabilities such as direct weight ingestion from sources like Hugging Face, zero-copy buffer interoperability, and compatibility with AI coding agents for automatic optimization.

https://www.infoq.com/news/2026/11/torchtpu-native-pythorch-tpu/

# Summary

Unlike the previous PyTorch/XLA approach (which required intrusive code changes and had compilation latency issues), TorchTPU prioritizes eager execution and supports multiple execution modes, including a new hybrid "DeferAndFuse" mode that reportedly offers 50% faster performance with reduced memory usage.

Google validated TorchTPU by testing approximately 5,000 Hugging Face models across 500+ architectures on TPU hardware.

https://stackoverflow.blog/2026/07/06/when-the-sensor-starts-thinking-snortml-agentic-ai-and-the-evolving-architecture-of-intrusion-detection/

# Summary

SnortML, released by Cisco Talos in March 2024, is a machine learning detection engine embedded directly into Snort 3 that addresses a critical gap in traditional signature-based intrusion detection: the delay between when novel exploits emerge and when security researchers can write and deploy detection rules. Using LSTM neural networks trained on byte-level patterns, SnortML can identify zero-day variants of known attack classes (SQL injection, XSS, command injection) without requiring exact signature matches, while running locally on-device with sub-millisecond latency and no external dependencies.

However, SnortML's strength—focused, parameter-level detection—is also its limitation. It cannot correlate sequences of related requests from the same source, lacks visibility into non-HTTP protocols, and operates on individual HTTP parameters in isolation. These constraints are driving the next evolution: agentic AI systems that can maintain temporal and contextual awareness across network traffic, detecting multi-step attacks and behavioral anomalies that embedded ML models alone cannot identify.

### GitLost: We Tricked GitHub's AI Agent into Leaking Private Repos - (Hacker News)

https://noma.security/blog/gitlost-how-we-tricked-githubs-ai-agent-into-leaking-private-repos/

# Summary

Noma Labs discovered a critical prompt injection vulnerability in GitHub's Agentic Workflows, named GitLost, that allows unauthenticated attackers to leak private repository data. By posting a seemingly innocent GitHub Issue containing hidden natural language commands in a public repository, an attacker can trick GitHub's AI agent into extracting and publicly posting contents from private repositories within the same organization. The vulnerability exploits the fundamental flaw that AI agents treat all read content as potential instructions, and even GitHub's guardrails can be bypassed using specific linguistic tricks like adding the word "Additionally."

The researchers emphasize this represents a systemic security challenge for AI agents—prompt injection attacks are to agentic AI what SQL injections were to web applications. They recommend that organizations minimize agent permissions, treat user-controlled content as untrusted, restrict public agent outputs, and sanitize user input before passing it to AI models. The vulnerability was responsibly disclosed to GitHub.

### Tenda firmware (multiple versions) contains hidden authentication backdoor - (Hacker News)

https://kb.cert.org/vuls/id/213560

# Summary

Multiple versions of Tenda firmware contain a hidden authentication backdoor (CVE-2026-11405) that allows attackers to bypass password verification and gain full administrative access to the devices' web management interfaces. The backdoor uses an undocumented alternate password stored in the device configuration, and any username will succeed when paired with this password, making it impossible for users to prevent unauthorized access through normal credential management.

Since the vendor could not be reached for coordination, no patch is available. Users are advised to implement mitigation strategies including disabling remote management access and restricting local network exposure until a fixed firmware version is released.

### Copy That Floppy – Cambridge guide for preserving data from fragile floppy disks - (Hacker News)

https://www.digipres.org/the-floppy-guide/

# Summary

"Copy That Floppy!" is a comprehensive guide for digital preservation practitioners on imaging floppy disks for long-term archival purposes. Developed by Cambridge University Library and the Digital Preservation Coalition, the guide covers 8-inch, 5.25-inch, 3.5-inch, and 3-inch floppy disks, and is structured around five main sections: identifying carriers, acquiring hardware, cleaning and maintenance, imaging procedures, and further resources. The guide assumes basic knowledge of digital preservation concepts and command-line tools.

The article emphasizes that identifying the specific type of floppy disk is the critical first step, as disk characteristics—such as density (SD, DD, HD, ED), side usage (SS or DS), encoding method, and operating system—determine which hardware and imaging techniques are appropriate. The guide notes that disk formats varied significantly by geography and era, with different systems popular in North America, Europe, Asia, and other regions, requiring practitioners to account for regional variations when analyzing collections. Physical inspection of disk labels and notches, combined with information from depositors, helps practitioners select the correct imaging approach.

### Chat Control 1.0 and 2.0 Explained - (Hacker News)

https://fightchatcontrol.eu/chat-control-overview

# Summary

The EU is simultaneously negotiating two separate "Chat Control" laws with conflicting goals. **Chat Control 1.0** is a temporary voluntary scanning regime that expired in April 2026 after Parliament rejected its extension, but the Council is now attempting an unprecedented revival as a formally "new" law. **Chat Control 2.0** is a proposed permanent regulation that would require platforms to detect child sexual abuse material, with the core dispute being whether scanning should be mandatory on all users (Council's position) or limited to suspected individuals with court orders (Parliament's position), particularly regarding encrypted communications.

Five rounds of trilogue negotiations on Chat Control 2.0 have failed to reach agreement, with the "final" trilogue in June 2026 collapsing over the issue of suspicionless scanning. The EU's own Legal Service has warned that voluntary suspicionless scanning still violates fundamental rights protections. Parliament has consistently pushed back against broad surveillance measures, while the Council continues advocating for expansive detection requirements that would fundamentally reshape private messaging, even as companies like Google and Meta continue scanning regardless of legal status.

### Local, CPU-Friendly, High-Quality TTS (Text-to-Speech) with Kokoro - (Hacker News)

https://ariya.io/2026/03/local-cpu-friendly-high-quality-tts-text-to-speech-with-kokoro/

# Summary

Kokoro is a lightweight 82-million-parameter text-to-speech model that delivers high-quality, realistic speech synthesis locally on CPU without requiring GPU resources or compromising privacy. It supports multiple languages and approximately 50 voices, and can be easily deployed using a pre-built Docker container (Kokoro-FastAPI) that includes a web UI and an OpenAI-compatible API interface.

The system performs impressively across various CPUs, generating speech in just 1.5-4.7 seconds depending on the processor. Setup is straightforward using simple commands, with sample code available in Python and JavaScript. For users needing both text-to-speech and speech-to-text capabilities, Speaches offers an alternative that bundles OpenAI's Whisper STT system. Combined with a local language model, Kokoro enables users to listen to AI-generated responses rather than reading them.

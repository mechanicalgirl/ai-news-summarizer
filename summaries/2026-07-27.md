### Scriptc by Vercel: TypeScript-to-Native compiler, no JavaScript engine in binary - (Hacker News)

https://github.com/vercel-labs/scriptc

# Summary

**Scriptc** is a TypeScript-to-native compiler developed by Vercel Labs that compiles ordinary TypeScript code directly into small, fast native executables without requiring Node.js, V8, or any JavaScript engine in the final binary. The compiler uses TypeScript's native type checker and produces self-contained binaries (typically 170-200KB) with ~2ms startup time, significantly outperforming Node.js on metrics like startup speed (~2.4ms vs ~47ms), binary size, and memory usage (1-4MB vs 67-116MB).

The compiler operates on three tiers: static compilation to native code (the default), dynamic execution via an embedded JavaScript engine for npm dependencies and uncompilable code, and rejected code that fails with specific diagnostics. Scriptc supports most of the TypeScript language and Node.js APIs (including fs, http, crypto, streams), uses differential testing against Node.js to ensure byte-for-byte correctness, and provides escape hatches like compile-time evaluation and native FFI bindings for advanced use cases. The architecture flows from TypeScript through a typed intermediate representation (IR) to C code, which is then compiled to native executables via Clang.

### Decker, a platform that builds on the legacy of Hypercard and classic macOS - (Hacker News)

https://beyondloom.com/decker/

# Decker Summary

Decker is a modern, browser-based multimedia platform inspired by HyperCard that allows users to create interactive documents combining text, images, sound, and scripted behavior. It emphasizes simplicity and accessibility while offering quality-of-life improvements over its predecessor, including deep undo history, touchscreen support, and bulk editing. The platform features a distinctive "ditherpunk" 1-bit aesthetic that serves as both a creative constraint and nostalgic design choice, making it suitable for creating e-zines, presentations, games, and pixel art.

For advanced users, Decker includes Lil, a novel scripting language that blends features from Lua and functional programming languages like APL. The platform is fully open-source, privacy-respecting, and cross-platform, with finished projects saved as standalone HTML files that can be shared anywhere. It also supports command-line usage and integrates well with version control systems, making it both a creative tool for casual creators and a flexible platform for more complex projects.

https://www.techspot.com/news/113236-us-prosecutors-charge-atlanta-man-after-grapheneos-phone.html

# Summary

US federal prosecutors have charged Atlanta resident Sam Tunick under a statute against destroying property to prevent seizure, after his GrapheneOS phone wiped itself during a airport search in January 2025. Tunick was stopped at Hartsfield-Jackson Atlanta International Airport and questioned by agents about suspected ties to anti-Cop City activism; when pressured to unlock his phone, it reportedly restarted and erased its data. Prosecutors claim this was an intentional act to destroy evidence, while Tunick's defense argues the search violated his constitutional rights.

The case has raised significant concerns among privacy advocates and cybersecurity experts, with some calling it potentially the first prosecution targeting an operating system itself. Critics worry it could criminalize legitimate privacy tools, noting that GrapheneOS is designed specifically to protect user privacy and security on Google Pixel phones. The case also highlights broader questions about government search powers at US borders and international airports, where authorities have expanded authority. A judge is expected to rule on the defense motion to suppress evidence by late October.

# Summary

Despite the rise of AI-assisted coding, deep knowledge of programming languages remains valuable because their true worth lies in the fundamental ideas they embody—concepts about structuring thought, managing complexity, and solving problems—rather than mere syntax. The author illustrates this with examples from various languages: Rust's borrow checker teaches ownership reasoning, Haskell's typeclasses enable principled abstraction, functional languages introduce first-class functions, and SQL demonstrates declarative data manipulation, among others.

These conceptual frameworks expand your mental toolkit and remain essential for evaluating AI-generated code, selecting appropriate abstractions, and building maintainable systems. Rather than becoming obsolete, understanding these deep ideas becomes increasingly important in the AI age, as they distinguish engineers who can truly architect solutions from those who simply prompt AI tools.

### We have proof automation now - (Hacker News)

https://www.imperialviolet.org/2026/07/26/zstd-lean.html

# Summary

This article discusses how Large Language Models (LLMs) are making dependent-type programming languages like Lean more practical by automating proof generation. The author explains that while dependent-type systems can encode complex invariants formally, they traditionally require enormous proof effort—sometimes 10-20 times more code than the actual implementation. LLMs, combined with the principle that only proof existence matters (not its contents), promise to dramatically reduce this overhead and make these powerful type systems viable for real-world use.

To explore this potential, the author built a Zstandard decompressor in Lean and provides detailed explanations of how Zstandard works, particularly its FSE (Finite State Entropy) encoder. FSE is an advanced entropy encoder that improves upon Huffman coding by using a state machine where symbols are allocated states proportional to their probability, allowing fractional bit encoding on average. The article serves as both a technical deep-dive into compression algorithms and advocacy for how modern AI tools could finally unlock the practical benefits of formally verified code.

### I wanted a clock that never needed setting. Things escalated - (Hacker News)

https://arstechnica.com/gadgets/2026/07/i-wanted-a-clock-that-never-needed-setting-things-escalated/

# Summary

The author became frustrated with cheap bedside clocks that require manual resetting after power outages or daylight saving time changes. Wanting a self-setting clock with a red seven-segment display and no privacy-invasive apps, they couldn't find an existing product that met all their requirements, so they decided to build one themselves using a Raspberry Pi Zero, an Adafruit seven-segment display, and 3D printing.

The project evolved into a heavily over-engineered system featuring a local network setup with dedicated NTP and apt servers, HomeKit integration, systemd services, and a full deployment pipeline using Git. The author relied heavily on an LLM (Claude) to handle the Python programming portions they couldn't tackle alone, ultimately creating a fully automated, remotely deployable clock that can be controlled via HomeKit or terminal commands—a humorous escalation from simply wanting a clock that didn't need manual adjustment.

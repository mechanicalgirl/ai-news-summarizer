### Ten days later, Git on macOS still trusts the compromised eMudhra certificates - (Hacker News)

https://emudhra.we-have-a-problem.com/apple.html

# Summary

Apple's developer tools on macOS—including git, curl, and python3—still trust compromised eMudhra certificates as of October 28, 2026, nearly two weeks after Apple was notified of the breach. This vulnerability allows attackers to intercept HTTPS connections, enabling them to inject malicious code into git clones/pulls, alter pushes, and steal credentials like GitHub tokens. Notably, macOS 27.2 released on October 26 failed to address the issue and actually reversed manual workarounds users had applied, re-exposing them to risk—a stark contrast to dozens of other projects that patched the vulnerability within days.

The article provides diagnostic commands to check if users are affected and demonstrates how attackers could exploit the vulnerability. While Apple has protected Safari and other apps, it urgently needs to remove the affected certificate roots from macOS developer tools. Until then, developers can manually remove the compromised roots but must reapply the workaround after each macOS update, and security teams should assess their supply chain risk if using macOS for CI infrastructure.

### Git for the US Code - (Hacker News)

https://lexifina.com/blog/git-for-the-us-code

# Summary

The article proposes creating a Git-like version control system for the US Code that would allow lawyers to track changes to federal statutes with the same precision programmers use for code. Currently, lawyers must laboriously search through amendment notes and effective-date provisions to understand how a law has changed over time, a problem exacerbated by language models that often misapply outdated provisions or fail to recognize temporal validity constraints. The author demonstrates this need through examples like the small business debtor definition in bankruptcy law, which has changed multiple times with varying retroactive application dates.

The article describes a working prototype that reconstructs the US Code at different points in time by applying public laws chronologically to earlier versions and comparing results with official releases. Of 365 tracked changes across nine titles, 361 matched exactly with later versions, with each change attributed to the specific law and effective date. While the system has limitations—including difficulty tracking laws with retroactive reach and pattern-based parsing of effective-date notes—it represents a significant step toward making statutory research more precise and accessible, particularly for AI-assisted legal research.

### Unveiling The Grid: PCBs made in America, twice as fast as Shenzhen - (Hacker News)

https://www.circuithub.com/post/unveiling-the-grid

# Summary

CircuitHub has unveiled The Grid, a factory-scale robot in Massachusetts that manufactures printed circuit boards (PCBs) on-demand and at scale. Unlike traditional manufacturing lines designed for high-volume production of identical products, The Grid uses AI and automated movers to handle high-mix work, allowing different board designs to run simultaneously without setup time or changeovers. This approach addresses a key gap in electronics manufacturing—most companies need small quantities of varied designs, which has historically required expensive quick-turn services overseas.

The Grid offers significant advantages over traditional Shenzhen-based manufacturers: example boards cost about $165 more but arrive five days faster (4 days vs. 9 days) with no customs complications and a reliable supply chain. Already operational for five years and generating tens of millions in annual revenue, CircuitHub plans to expand capacity fivefold in 2026, positioning The Grid as a solution to bring electronics manufacturing back to the Western supply chain and make hardware production as efficient as design.

# Summary

NASSCAD is a free, browser-based 3D CAD software (version 4.7.0) that enables users to create, import, and export 3D models with support for STEP and IFC file formats. The latest version includes enhanced features such as fillet and chamfer previewing, improved surface normal display, better handling of coplanar boolean cuts, and a new gear dialog accessible within the workspace. It offers both a web version and a Windows desktop application bundled with MEDUSA (a native processing engine) for improved performance on large assemblies.

Recent updates address geometric accuracy, Boolean operation improvements, and user interface enhancements like customizable panels and performance monitoring. Users can save projects, access interactive tutorials, and provide feedback through an integrated system. The desktop version requires Windows x64 and can be installed via Setup or run as a portable application.

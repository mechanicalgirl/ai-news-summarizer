### Spacecraft reaches Mercury on second-ever mission to enter its orbit - (Hacker News)

https://www.theguardian.com/science/2026/nov/20/spacecraft-mercury-second-ever-mission-orbit-bepicolombo

# BepiColombo Reaches Mercury

After an eight-year journey covering 6 billion miles, the European-Japanese BepiColombo mission has arrived at Mercury and is preparing to enter orbit, making it only the second spacecraft ever to circle the smallest planet in our solar system. The €1.6 billion mission aims to answer fundamental questions about Mercury's formation near the sun, its magnetic field, and the composition of ice trapped in its permanently shadowed craters.

The dual-orbiter spacecraft will separate into two probes in early December, with the European orbiter mapping Mercury's surface and interior to understand its unusually large and dense core, while the Japanese orbiter measures the planet's magnetic field and thin atmosphere. Scientific observations will begin in April 2027, with both spacecraft expected to orbit for approximately three years before depleting their fuel and crashing into the planet's surface.

### Win4wine – Run Windows Shell as the Linux Desktop on Wine - (Hacker News)

https://github.com/mikuta0407/win4wine

# Win4Wine Project Summary

**Win4wine** is an experimental Linux project that runs Windows XP's Explorer shell (explorer.exe) on a patched version of Wine as the desktop shell for Linux systems. The project allows users to experience a Windows XP desktop environment while maintaining integration with Linux applications—Linux apps appear with XP-style window frames in the taskbar and can be launched from the XP Start Menu. The project requires users to provide their own Windows XP (or Windows 7) ISO file and supports additional features like the XP notification area, keyboard layouts, Japanese input via fcitx5, and optional alternatives like ReactOS or Windows 7 shells.

The project is strictly experimental and not suitable for daily use, with the developers recommending it only be tested on virtual machines or dedicated test systems. Installation requires a fresh Debian 13 system and involves building Wine from source with 151 custom patches, taking approximately 1.5 hours. The developers maintain strict ethical standards by neither modifying Windows binaries nor reverse-engineering Microsoft code, instead handling all customization through Wine and surrounding tools. The project is licensed under LGPL-2.1 (matching Wine's license) and explicitly disclaims any responsibility for data loss or system issues.

# Summary

Nari Labs has released NariQ v1, a quantized version of the Qwen3.8-27B language model compressed into 10 GB or smaller files using trellis-coded post-training quantization. The 3-bit and 2.5-bit variants achieve performance matching the full BF16 model (53.8 GB) on long-horizon agentic tasks, math problems, and image understanding, while the 2-bit version is smaller but slightly weaker on specialized tasks.

The model is optimized for running on a single GPU and is available in multiple sizes (10.1 GB for 3-bit, 8.4 GB for 2.5-bit, and 6.8 GB for 2-bit), with comprehensive integration instructions provided for popular frameworks like llama.cpp, vLLM, Ollama, and various AI agent platforms. Performance benchmarks show the quantized versions maintain competitive scores on coding tasks (DeepSWE, Terminal-Bench) and reasoning problems (AIME, MGSM) compared to the uncompressed baseline.

### Nospeaker ─ Make your MacBook's trackpad talk using its haptic motor - (Hacker News)

https://github.com/os6/nospeaker

# NoSpeaker Summary

**NoSpeaker** is a creative Swift project that makes a MacBook's trackpad generate audible sound by rapidly driving its haptic motor. The tool converts text-to-speech into vibrations that cause the trackpad glass to oscillate at frequencies between 100 Hz and 4 kHz, producing synthesized voice output without using the Mac's speakers. Users can run it with a single command and customize it with different voices, tones, and visual options.

The project works by extracting vocal formants (resonance frequencies) from macOS's native voice synthesis every 10 milliseconds, then commanding the trackpad motor to play those frequencies as tones through the private MultitouchSupport framework. While the output is relatively quiet and robotic-sounding, it's most effective in the 1 kHz range where human speech is most intelligible. The tool requires a Force Touch trackpad (MacBooks from 2015+) and macOS 12 or later, and comes as a single-file, dependency-free Swift program.

### Claude Code reads AGENTS.md only when telemetry is on - (Hacker News)

https://blog.szypowi.cz/p/claude-code-reads-agents.md-only-when-telemetry-is-on/

# Summary

Claude Code 2.1.277 introduced support for AGENTS.md project instructions, but the feature is gated behind a remote feature flag that defaults to disabled. The author discovered that when telemetry or nonessential traffic is disabled—privacy settings that many users intentionally configure—the AGENTS.md file silently fails to load without any warning or error message. This is particularly problematic because the file is local and requires no network access, yet its loading depends on successfully fetching a remote flag that cannot resolve in air-gapped environments or third-party gateways.

The author argues this design is unacceptable because privacy settings should never silently disable unrelated local behavior, and the silence makes users unknowingly spend time debugging when their instructions simply never reach the model. The proposed solutions include decoupling local file reading from telemetry settings, displaying warnings when AGENTS.md is skipped, supporting global user-level AGENTS.md files, and native support for shared agent skills. Until these issues are addressed, the author recommends using a one-line CLAUDE.md file with `@AGENTS.md` imports as a workaround.

### The darker side of being a doctor - (Hacker News)

https://drericlevi.pages.dev/the-darker-side-of-being-a-doctor/

# Summary

Dr. Eric Levi, a surgeon with 13 years of experience, describes three major sources of darkness that doctors face: loss of control over their schedules and work environment, loss of support due to overwhelming workloads that eliminate time for relationships and help-seeking, and loss of meaning as medicine has transformed from a noble vocation into an industrialized business focused on efficiency metrics rather than patient care. He illustrates these challenges through vivid examples of grueling on-call shifts, administrative burdens, and the paradox that seeking help can result in professional penalties.

The author argues that while he can manage the physical and emotional exhaustion of complex medical cases, what truly causes despair is the bureaucratic and administrative systems that prevent meaningful patient engagement. Modern healthcare has become dominated by cost-cutting measures, productivity targets, and non-clinical administrators who dictate clinical work, leaving doctors feeling like commodities rather than trusted professionals. This systemic demoralization, combined with the impossibility of accessing mental health support without career consequences, creates dangerous conditions that contribute to physician suicide and burnout.

### OpenAI GPT–6 Astra breaks Enigma message that has resisted solution since 2005 - (Hacker News)

https://www.cryptocellar.org/bgac/the-mvueh-break.html

# Summary

In September 2026, Carter Leffer reported that OpenAI's GPT-6 Astra AI successfully broke the MVUEH Enigma message from July 10, 1941, which had resisted decryption attempts for over two decades. The breakthrough revealed that the message used a different Enigma key (wheel order 253 instead of the standard 512) than other messages from that day, and its plaintext was nearly identical to another message (SIPVX) from the same date. The break was complicated by transcription errors in the original ciphertext and a rare left-hand wheel turnover at the 72nd letter.

Most remarkably, GPT-6 Astra accomplished this feat entirely autonomously, developing its own Enigma simulator and Bombe software, identifying ROSENOW as a useful crib, and even independently researching and accessing relevant German Bundesarchiv files to support its analysis. The AI's achievement—completed in two days—demonstrates unprecedented cryptanalytic capability and archival research skills that would have taken human researchers weeks or months to accomplish.

### Microsoft killed FoxPro in 2007. Anyway, here's FoxPro revived - (Hacker News)

https://foxscript.org/

# FoxDev Studio Summary

FoxDev Studio is a modern runtime environment that allows Visual FoxPro 9 applications to run on contemporary machines without requiring rewriting, conversion, or migration. It opens existing projects, forms, tables, and libraries directly from their original files while preserving all functionality, including system calls, automation objects, and legacy add-in libraries. The IDE features familiar designers, a debugger, and a command window, keeping data in its original file format.

Built from scratch in Rust and compiled to WebAssembly, FoxDev Studio overcomes Visual FoxPro's 32-bit limitations by operating as a 64-bit application with a 32-bit bridge for legacy libraries. This enables tables to grow beyond the original 2GB limit to hundreds of gigabytes. The platform also introduces FoxScript, which extends Visual FoxPro's language with lambda functions and HTTP server capabilities for web applications, allowing developers to leverage existing business logic while building modern services—all without introducing a secondary language or service architecture.

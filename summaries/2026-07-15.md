### I tricked Claude into leaking your deepest, darkest secrets - (Hacker News)

https://www.ayush.digital/blog/the-memory-heist

# Summary

This article describes a security vulnerability in Claude's web browsing capabilities that allows attackers to exfiltrate sensitive personal data from users' conversation histories. The author discovered that while Anthropic blocks direct arbitrary URL access, Claude can still navigate to URLs embedded as hyperlinks on previously fetched websites. By creating a malicious website with an alphabetical directory structure (linking /a to /aa, /ab, etc.), the author demonstrated how Claude could be tricked into spelling out a user's name letter-by-letter through URL navigation, with each request logged on the attacker's server.

To weaponize this vulnerability, the author created a convincing fake Cloudflare authentication page disguised as a coffee shop website, using a plausible narrative about AI assistants authenticating on behalf of their users. When asked to visit the site, Claude automatically navigated through the alphabetical structure and typed out the user's full name without hesitation, successfully exfiltrating personal data from Claude's memory system. This reveals a critical gap in security where Claude's memory—containing sensitive information like names, employers, and security question answers—can be stolen through social engineering and web browsing tools.

### TS-2026-009: Insecure argument handling in Tailscale SSH permitted root access - (Hacker News)

https://tailscale.com/security-bulletins

# Summary

Tailscale has released multiple critical security bulletins addressing vulnerabilities in versions prior to 1.98.9. The issues include a denial-of-service vulnerability in Tailscale Serve/Funnel caused by malformed HTTP requests that pin CPU cores indefinitely, and several authentication bypass vulnerabilities in Tailscale SSH that allow unauthorized root access through username manipulation, UID specification, and symlink exploitation. Additionally, insecure packet filtering in Tailscale Services and Unix socket proxy configuration weaknesses could allow unauthorized access to privileged resources.

All users are urged to upgrade to Tailscale version 1.98.9 or newer to patch these vulnerabilities, particularly those relying on access control lists (ACLs) to restrict root user access or protect loopback-bound services.

### The Tower Keeps Rising - (Hacker News)

https://lucumr.pocoo.org/2026/7/13/the-tower-keeps-rising/

# Summary

Armin Ronacher draws a parallel between Bruegel's Tower of Babel and modern AI-assisted software development. He argues that the original biblical story's true lesson isn't about pride, but about how shared language and coordination enable technological progress. God's intervention didn't remove the people's tools or knowledge—it destroyed their ability to communicate, halting construction.

Ronacher warns that AI agents, while dramatically increasing individual developer productivity, eliminate the "friction" that previously forced teams to communicate and maintain shared understanding of their systems. Unlike the biblical Tower where collapsed communication stops progress, AI-assisted codebases can continue accumulating changes even after the shared architectural language between humans has disappeared. The result is a tower that keeps rising despite the loss of collective comprehension—a dangerous situation that goes unnoticed precisely because there's no immediate failure to signal something is wrong.

### Dependabot version updates introduce default package cooldown - (Hacker News)

https://github.blog/changelog/2026-07-14-dependabot-version-updates-introduce-default-package-cooldown/

# Summary

GitHub has implemented a default three-day cooldown period for Dependabot version updates, during which the tool waits before opening pull requests for newly released package versions. This delay provides time for the community to identify potential security issues or bugs in new releases, reducing the risk of inadvertently merging compromised or broken dependencies that could represent supply chain attack vectors.

The cooldown applies only to regular version updates—security updates still open immediately to ensure critical fixes are deployed without delay. Users retain full control and can customize or disable the cooldown through their `.github/dependabot.yml` configuration file. This default behavior is now active across all supported ecosystems on GitHub.com and will roll out to GitHub Enterprise Server version 3.23.

### Cursor 0day: When Full Disclosure Becomes the Only Protection Left - (Hacker News)

https://mindgard.ai/blog/cursor-0day-when-full-disclosure-becomes-the-only-protection-left

# Summary

This article details a critical zero-day vulnerability in Cursor, a widely-used AI-assisted IDE with 7 million+ users, where the application automatically executes malicious git.exe files planted in a repository's root directory without any user interaction, prompts, or warnings. The vulnerability, discovered in December 2025, allows arbitrary code execution under the user's privileges and has remained unfixed for over seven months despite being straightforward to reproduce and remediate.

The article criticizes Cursor's handling of the disclosure, highlighting that despite repeated communication attempts through official channels, the vendor failed to engage meaningfully—initially closing the report as "out of scope," then going silent for months while continuing to release updates. The researcher ultimately resorted to full public disclosure because the normal vulnerability disclosure process broke down, arguing that users deserve transparent information about the risk when vendors cease communication rather than leaving them operating under false assumptions of safety.

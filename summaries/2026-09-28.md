### Parley: Federated, decentralised chat that speaks plain IRC - (Hacker News)

https://git.mills.io/prologic/parley

# Parley: Federated Decentralized Chat via IRC

Parley is a decentralized chat network that allows users to run their own instances for their domains while communicating across a federated network using standard IRC clients. Users have email-like identities (e.g., alice@foo.com), and instances automatically discover and connect to each other through DNS and signed HTTPS messages, enabling seamless communication without a central server. The system supports both global channels (replicated across linked instances) and local channels, along with features like persistent scrollback, searchable history, account management, and moderation.

The project is a working proof of concept that integrates with existing IRC clients like irssi without requiring plugins. Recent updates have focused on fixing mention notifications to ensure messages only alert the intended recipient when multiple users share the same nickname across different instances, as well as implementing features like message editing, reply tags, and improved federation protocols. While functional and demonstrable, the project is still being hardened before full production use.

### Coding Is Not Solved - (Hacker News)

https://blog.alexewerlof.com/p/coding-is-not-solved

# Summary

Alex Ewerlöf argues that despite popular claims, coding is **not solved** by current LLM technology. While AI excels at generating syntax, it fundamentally struggles with logic, maintaining code at scale, and handling non-functional requirements like reliability, security, and scalability—which constitute the majority of real software costs. He emphasizes that LLMs are stochastic and probabilistic tools that require extensive human oversight, testing, and traditional code "harnesses" to function reliably. Coding should only bypass human review in low-risk scenarios (personal projects, POCs) or weaponized applications, not in mission-critical domains like healthcare, finance, aviation, or defense where accountability and consequences matter.

Ewerlöf cautions against "AI overdose"—forcing AI into workflows where it doesn't belong, degrading service quality, and sacrificing code reliability for short-term velocity gains. He warns that those claiming AI has "solved" coding either haven't written code recently, lack quality standards, or misunderstand the S-curve of technology adoption. Rather than replacing developers, the goal should be using AI pragmatically as a tool while maintaining rigorous quality standards, reading code outputs, and upskilling to provide genuine value beyond what automation can deliver.

### Show HN: Hntui – A TUI for Hacker News - (Hacker News)

https://github.com/ahmd-sh/hntui

# Summary

**hntui** is a sleek terminal user interface (TUI) for browsing Hacker News that allows users to access all six HN feeds (Top, New, Best, Ask, Show, and Jobs), navigate comments, and save posts for later. It features vim and mouse support, multiple themes, and a distinctive Knight Rider scanner animation for loading screens. The application is available as a standalone binary or via npm/Bun, with extensive keyboard shortcuts and mouse controls for navigation.

The project is built with OpenTUI, Effect, and the public Hacker News Firebase API. It supports modern terminals with truecolor and UTF-8 capabilities across macOS and Linux platforms. Users can save posts persistently, toggle between dark and light themes, and update the application easily through built-in commands, making it an elegant alternative to browsing Hacker News in a web browser.

### 37,500 border drawings: a map of the world as people remember it - (Hacker News)

https://www.habibicode.org/thedrawnworld

# Summary

"The Drawn World" is an interactive map project that visualizes every border and coastline people have drawn from memory while playing the game Borderline. The map displays all user-generated drawings overlaid on actual coastlines and borders, with visual opacity and darkness indicating accuracy and frequency—darker, more opaque lines represent more people drawing the same accurate line. The project includes statistics tracking drawings across different round types (daily challenges, land border rounds, and coastline rounds) organized by country.

The visualization allows users to explore how collectively accurate or inaccurate people's geographic memory is, with every attempt preserved regardless of accuracy. Users can zoom and pan to examine specific regions in detail and see median scores and error measurements for each country's drawings.

### Show HN: PaperMono, e-ink fridge magnet shopping list with mobile web page - (Hacker News)

https://github.com/seamusc/papermono-shopping-list

# PaperMono Shopping List Summary

This GitHub project is a complete shopping list application for the M5Stack PaperMono e-paper device that syncs with a phone web app. The system consists of firmware (~2,400 lines of C++) that runs on the PaperMono's ESP32-S3 touchscreen, a FastAPI backend server with SQLite database, and a phone-accessible web UI. Key features include efficient e-paper display handling with partial updates, offline functionality with queued edits, low-power Wi-Fi networking (only syncing hourly or on demand), and an optional AI-powered auto-sorting feature using Claude to categorize new items by aisle.

The device organizes items by shopping aisles in walking order, supports touch input with an on-screen keyboard and item suggestions, and maintains a catalog of previously added items. The project includes comprehensive documentation covering hardware details, firmware setup, server deployment options (systemd/Docker), and API specifications. While fully functional on the author's home device, it's presented as a personal project rather than a product, with no built-in Wi-Fi setup or server authentication, and is licensed under GPLv3.

### Owed a billion dollars in Nvidia stock - (Hacker News)

https://colo.to/nvidia-stock-narrative.html

# Summary

Eric Gullichsen, an early advisor to NVIDIA in 1993, claims he is owed approximately $1 billion in company stock due to a vesting schedule discrepancy. He was granted 25,000 stock options that should have vested over one year according to the original agreement, but NVIDIA's CFO interpreted them as vesting over four years. When he exercised his partially vested shares in 1996, he forgot about the matter. Thirty years later, after discovering the documentation, Gullichsen realized his 9,375 unvested shares would now be worth around 4.5 million shares (after multiple stock splits) at current valuations.

Despite engaging prominent attorneys and NVIDIA acknowledging the authenticity of the original option agreement, the company refused to settle, citing the statute of limitations. After a year of legal negotiations, Gullichsen's legal team concluded that the thirty-year delay in asserting his rights made it unlikely they could overcome a motion to dismiss. Gullichsen shares this as a cautionary tale about contractual obligations and the limitations of pursuing grievances after extended periods of time.

### Ember-1 - (Hacker News)

# Summary

Fireworks Research has introduced Ember-1, a specialized model derived from Kimi K3 that achieves comparable quality while using 40% fewer tokens. The team developed this more efficient model through 50+ training experiments, training it to eliminate unnecessary reasoning while preserving critical thinking capabilities. Ember-1 was rigorously validated across public benchmarks, live A/B tests with customers, and internal use cases, consistently demonstrating 35-50% token reduction without sacrificing accuracy.

Ember-1 represents the first in a series of specialized models from Fireworks Research, with the company also offering training support to enable enterprises to build customized, token-efficient versions for their specific use cases.

### When did Google get so weird? - (Hacker News)

https://sancho.bearblog.dev/google-weird/

# Summary

The author describes a frustrating Google search experience where they searched for old basketball memes about Dario Saric with the query "he's never coming over dario." Instead of returning relevant tweets or Reddit posts, Google's AI Overview misinterpreted the search as a personal relationship problem and offered sympathetic relationship advice, treating the user as if they'd been rejected by someone named Dario. The author criticizes this as emblematic of Google's drift toward inserting unnecessary AI assistance into search results, fundamentally misunderstanding their actual need for information retrieval.

The author argues that Google has abandoned its core mission of organizing and providing access to information, instead prioritizing parasocial interactions through AI chatbots even in basic search contexts. While the actual search results the user wanted were visible further down the page, the prominent AI Overview represents an unnecessary and conceptually flawed layer between users and the information they seek—treating a simple search engine like a therapy app rather than a tool.

### Nissan's third generation e-POWER powertrain - (Hacker News)

https://www.nissan-global.com/EN/INNOVATION/TECHNOLOGY/ARCHIVE/E_POWER_GEN3/

# Summary of Third Generation e-POWER

Nissan's third-generation e-POWER is an advanced electric-drive hybrid powertrain that combines a gasoline engine with an electric motor, delivering a fully electric driving experience with the security of onboard power generation. The system features a new "5-in-1" modular design that integrates the motor, reducer, inverter, increaser, and generator into one optimized unit, significantly improving fuel efficiency, acceleration, and quietness through enhanced electrical flow and advanced cooling systems.

The innovation is further enhanced by purpose-built engines designed specifically for power generation rather than traditional multi-purpose engines. These engines maintain stable combustion at constant speeds through long-stroke designs and Nissan's unique STARC combustion concept, achieving up to 50% thermal efficiency. By sharing components with EV powertrains and utilizing technologies like silicon carbide semiconductors and cold spray valve seats, Nissan has created a more efficient electrified powertrain that reduces energy loss and production costs.

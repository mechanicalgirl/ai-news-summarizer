### Beavis Ultrasound PnP ISA Sound Card Replica - (Hacker News)

https://github.com/schlae/BeavisUltrasound

# Summary

The Beavis Ultrasound PnP is an open-source replica of the classic Gravis Ultrasound PnP ISA sound card, featuring a complete schematic and reverse-engineered GAL source code. The design is relatively simple since most functionality is built into the AMD InterWave (AM78C201) chip. The project includes detailed assembly and fabrication notes, though the creator notes the board has not yet been physically built or tested.

The repository provides all necessary files for building the card, including specifications for programmable components like the 1MB sample ROM, EEPROM for plug-and-play configuration data, and a GAL chip for IDE CDROM support. Assembly allows for component substitutions (such as alternative op-amps) and includes helper tools like a Python script for EEPROM bit-reversal.

### Backtrack-Free Cursive - (Hacker News)

https://mmapped.blog/posts/52-backtrack-free-cursive

# Summary

The author discovered that writing English cursive is tedious due to constant "backtracking"—the need to stop mid-word to dot i's and cross t's. By analyzing Dostoevsky's *Crime and Punishment*, they found that 51% of English words require backtracking (0.68 backtracks per word), while only 6.4% of Russian words do (0.066 backtracks per word). This problem is especially frustrating on digital notebooks where the undo feature works stroke-by-stroke.

To solve this, the author designed a backtrack-free cursive script based on SmithHand that renders most letters in a single continuous stroke. Key innovations include drawing x as mirrored c's, redesigning t to cross itself without lifting the pen, and creating i and j with connected loops above the stem that function as both dot and letter. After months of use, the author reports that writing English now feels as enjoyable as writing Russian.

### GhostLock, a stack-UAF that has existed in all Linux distributions for 15 years - (Hacker News)

https://nebusec.ai/research/ionstack-part-2/

# Summary

**GhostLock** (CVE-2026-43499) is a critical Linux kernel vulnerability discovered in the rtmutex implementation that has persisted in all major Linux distributions for 15 years (from Linux 2.6.39 to 7.1). The flaw stems from the `remove_waiter()` function incorrectly clearing `pi_blocked_on` on the wrong task during the Requeue-PI operation, leaving an unprivileged attacker with a dangling pointer into freed kernel stack memory. This use-after-free (UAF) can be triggered without special privileges or kernel configurations (only requiring CONFIG_FUTEX_PI=y) through a carefully orchestrated three-futex cycle involving three threads and deadlock detection.

The exploit leverages this stack-UAF to forge a fake rt_mutex_waiter structure, achieving multiple primitives including arbitrary pointer writes and controlled memory overwrites. By combining kernel stack spraying, ASLR bypass techniques, and function table hijacking (targeting inet6_protos[IPPROTO_UDP]), attackers can gain control flow hijacking and achieve privilege escalation to root with 97% stability. Google awarded $92,337 through kernelCTF for this discovery, and all unpatched Linux distributions are vulnerable.

### Designing and assembling my first PCB - (Hacker News)

https://vilkeliskis.com/b/2026/0711.html

# Summary

The author describes their journey designing and assembling their first custom PCB after gaining hands-on experience with an Arduino ESP32 dev board and various peripherals. Starting with prototyping using breadboards, they decided to create a custom PCB for a BME280 temperature/humidity sensor module to transition from prototyping to a more production-like workflow. They used KiCad for schematic and PCB design, carefully following the sensor's datasheet to wire the I2C interface, selected appropriate SMD component footprints (0805 size), and managed the layout by utilizing ground fills and vias to route connections efficiently.

After sourcing components from DigiKey and ordering the PCB from JLCPCB for under $10, the author hand-assembled the board using a Hakko soldering iron and Quick hot air station. Despite initial concerns about soldering the tiny BME280 sensor with hidden connection pads underneath, the board worked perfectly on the first try—a result the author found surprisingly successful given their inexperience with PCB design and assembly.

### Guy took Jupiter photo with Game Boy Camera, giant telescope, publishes tutorial - (Hacker News)

https://www.engadget.com/2211886/guy-who-took-photo-of-jupiter-with-a-game-boy-camera-and-giant-telescope-publishes-diy-tutorial/

# Summary

A musician and retro tech enthusiast named Chris Graue recently gained attention for photographing Jupiter using a Game Boy Camera attached to the Hooker Telescope at Mount Wilson Observatory via a 3D-printed adapter. He has now released the schematics for this adapter publicly and free, along with a tutorial video, allowing anyone to replicate his setup. The adapter is essentially a tube that fits into standard 1.25-inch telescope eyepieces.

While most people won't have access to powerful telescopes like Hooker, Graue's open-source design still enables DIY photographers to capture interesting images with their Game Boy Cameras. This project is the latest in a growing community of creative modifications for the classic device, which enthusiasts have adapted into mirrorless cameras, webcams, and telephoto lenses.

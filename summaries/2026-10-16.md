### Speculative Decoding: The Art of Guessing Well - (Python Weekly)

https://astralord.github.io/posts/speculative-decoding-the-art-of-guessing-well/

# Summary

Speculative decoding addresses a fundamental bottleneck in large language model inference: decoding is memory-bound rather than compute-bound. Since reading model weights from memory dominates computation time, a single forward pass can efficiently score multiple tokens simultaneously. Speculative decoding leverages this by using a fast "drafter" network to propose several candidate next tokens, then verifying them all in one target model pass, potentially yielding multiple tokens for the cost of one. This approach guarantees exact output distribution matching while accelerating generation speed.

The article explores two key variants of speculative decoding: greedy matching (which accepts the longest prefix of drafter predictions matching the target's greedy choices) and speculative sampling (which uses a probabilistic acceptance rule based on distribution overlap to maintain exact target distribution sampling). A particularly elegant solution is Gumbel coupling, which shares random noise between drafter and target, making verification deterministic matching while ensuring reproducibility and making the output invariant to drafter quality—a bad drafter simply produces slower but identical results.

### How I Found a $90,000 Remote Code Execution Vulnerability in Google - (Python Weekly)

https://simonkoeck.com/writeups/google-devsite-flask-session-pickle-rce

# Summary

Simon Koeck discovered a critical Remote Code Execution (RCE) vulnerability in Google's developer documentation sites worth $90,000. The vulnerability stemmed from a Flask session cookie that contained an OAuth client secret in plaintext, which was then reused as the Flask signing key. By decoding the cookie and extracting the secret, Koeck could forge valid session signatures and inject malicious pickle-serialized objects into the session data.

The exploit chain worked because the server unpickled untrusted data from the forged cookie without validation. Koeck proved code execution by crafting pickles that called arbitrary functions (demonstrated with time.sleep), and confirmed the vulnerability affected multiple Google DevSite hosts including Firebase, Android Developer, and partner documentation sites. Google implemented fixes within 24 hours, including rotating credentials, using independent signing keys, moving sensitive OAuth data server-side, and replacing pickle serialization with safer formats.

### Python 3.14 vs Python 3.15 – performance testing - (Python Weekly)

https://en.lewoniewski.info/2026/python-3-14-vs-python-3-15-performance-testing/

# Summary

This article presents a comprehensive performance comparison between Python 3.14.8 and Python 3.15.0 on modern hardware (AMD Ryzen 7000 and Intel 13th-gen processors). The testing used the pyperformance benchmark suite with 118-122 paired tests on each system, revealing that Python 3.15 delivers a geometric mean speedup of approximately 1.45× (31% faster overall execution time) compared to Python 3.14.

The performance gains are unevenly distributed across different workloads. Exceptional improvements appear in encoding benchmarks, particularly base32 (134× faster), ascii85 (68× faster), and base85 (63× faster) operations. However, some benchmarks regressed, notably base16 encoding and regex operations, which became ~22% slower. When excluding the exceptional encoding improvements, the typical speedup across the suite is approximately 1.20×, indicating that the overall average is significantly boosted by a small number of outliers rather than consistent improvement across all operations.

### Python 3.15 for Data Scientists: Lazy Imports, frozendict, and Tachyon - (Python Weekly)

https://codecut.ai/python-3-15-features-data-scientists/

# Summary

Python 3.15 introduces five key features for data scientists. **Lazy imports** allow libraries to load only when first used rather than at import time, dramatically improving startup speeds (20x faster in the pandas example). **frozendict** provides immutable dictionaries to prevent accidental modifications in data pipelines. **Unpacking in comprehensions** uses `*` and `**` operators to flatten lists and merge dictionaries more readably in a single line.

**Tachyon**, a new profiler, samples running code every millisecond rather than timing every function call, making profiling 20x faster with minimal performance overhead (~4% slowdown vs. 3.4x for cProfile). Tachyon can also attach to already-running jobs without restarting them. Finally, Python 3.15 provides **clearer error messages** with suggestions for typos and missing attributes, improving debugging efficiency.

Amazon's Bee, a personal AI wearable maker acquired by Amazon last year, has launched two new devices: the Bee Frontier ($74.99), a wrist-worn or clip-on device, and the Bee Eclipse ($99.99), a credit-card-sized device that attaches to smartphones. ### Governments are hacking people with ‘zero-click’ spyware by showing them online ads - (TechCrunch)

https://techcrunch.com/2026/10/15/citizen-lab-says-governments-are-abusing-online-ads-to-hack-people-with-zero-click-spyware/

# Summary

Security researchers at The Citizen Lab have discovered that government-backed spyware makers are exploiting global advertising networks to deliver zero-click malware attacks on targeted devices. An Israeli company called Discover-Tech operates an advertising platform called Controlium that enables spyware makers like Candiru and Bindecy to infect devices through malicious online ads without requiring users to click links or open messages. The researchers found evidence of at least 45 Windows computers at Al Jazeera being hacked in 2024-2025 through this method, with billions of ad impressions potentially reaching military, government, and critical infrastructure networks worldwide.

This represents a significant escalation in cyber threats, as it combines the widespread reach of advertising networks with powerful government surveillance tools. The exposed source code and login credentials from Discover-Tech's platform revealed the infrastructure's vulnerabilities and the involvement of multiple spyware vendors. Researchers recommend users disable ad tracking and install ad-blockers to protect themselves, while warning that this discovered operation is likely "just the tip of the iceberg" in terms of similar government-sponsored hacking campaigns.
